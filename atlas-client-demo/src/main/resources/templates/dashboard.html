Atlas Client(atlas-client-*)로 실제 Atlas에 접속해 클라이언트 기능을 확인하는 데모 앱입니다. 모든 화면 아래에 그 화면에서 클라이언트가 보낸 HTTP 요청이 표시됩니다.

Atlas에 접속하지 못했습니다. docker compose로 띄운 직후라면 Atlas가 ACTIVE가 될 때까지 몇 분 걸립니다. 잠시 뒤 새로고침하세요.

타입

둘러보기

  1. 샘플 데이터를 만들면 타입, 테이블, classification, 리니지가 한 번에 생깁니다.
  2. 엔티티 검색에서 상세 화면으로 들어가 classification, label, 속성을 바꿔 봅니다.
  3. 리니지에서 그래프와 영향도를 봅니다.
  4. 타입 plan/apply로 정의를 바꾸고 plan 결과를 확인합니다.
  5. Kafka에서 hook 메시지를 보내고 변경 이벤트를 실시간으로 봅니다.
