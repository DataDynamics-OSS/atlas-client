Apache Atlas란?

Atlas는 조직의 데이터에 대한 데이터(메타데이터)를 모아 두는 카탈로그입니다. 데이터 자체가 아니라 "어떤 테이블이 있는지, 누가 관리하는지, 개인정보가 들어 있는지, 어떤 작업이 이 테이블을 만드는지"를 저장합니다.

Atlas를 이해하는 데 필요한 단어는 몇 개뿐입니다.

타입메타데이터의 설계도. 예: "테이블은 이름, owner, 컬럼을 가진다"
엔티티타입으로 만든 실제 기록. 예: sales.orders@prod 테이블
classification엔티티에 붙이는 분류 태그. 예: 개인정보(PII)
리니지데이터가 어떤 작업을 거쳐 어디로 흐르는지의 기록

이 데모 앱은?

Atlas Client(Java 라이브러리)의 기능을 화면에서 직접 실행해 보는 도구입니다. 각 화면의 버튼은 라이브러리의 메서드를 호출하고, 그 결과와 함께 라이브러리가 Atlas에 실제로 보낸 HTTP 요청을 보여줍니다. 코드를 쓰기 전에 "이 메서드가 무엇을 하는지" 확인하는 용도입니다.

오른쪽의 이 도움말은 화면마다 바뀝니다. 위쪽 "? 도움말" 버튼이나 × 로 숨기고 다시 열 수 있습니다.

대시보드 읽는 법

Atlas

  • 상태: ACTIVE면 정상입니다. PASSIVE는 HA(이중화) 구성의 대기 서버, "접속 불가"는 Atlas가 꺼져 있거나 아직 시작 중인 것입니다. docker compose로 막 띄웠다면 몇 분 기다리세요.
  • 서버: 접속하는 Atlas 주소. 여러 개면 클라이언트가 그중 ACTIVE인 서버를 스스로 찾아 씁니다.

Kafka

Atlas가 쓰는 Kafka 주소와, Atlas의 변경 알림을 받는 ATLAS_ENTITIES 리스너 상태입니다. "수신 중"이면 정상입니다.

타입

카테고리별 타입 수입니다. 누르면 그 카테고리의 타입 목록으로 갑니다. 카테고리 뜻은 타입 화면 도움말에 있습니다.

각 화면 아래의 요청 표

"이 화면에서 클라이언트가 보낸 요청"에는 그 화면을 그리면서 보낸 요청이 나옵니다. 이 대시보드는 상태, 버전, 타입 목록 세 가지를 조회합니다.

  • 경로를 누르면 요청 본문과 응답 본문이 펼쳐집니다.
  • 시도가 2 이상이면 클라이언트가 자동으로 재시도한 것입니다.
  • 빨간 행은 실패한 요청입니다.

추천 순서

  1. 샘플 데이터: 버튼 하나로 타입, 테이블, 분류, 리니지를 만듭니다.
  2. 엔티티: 만든 테이블을 검색하고 상세 화면에서 분류·레이블·속성을 바꿔 봅니다.
  3. 리니지: 테이블 사이의 흐름 그래프와 영향도를 봅니다.
  4. 타입 plan/apply: 타입에 속성을 추가해 보고, Atlas가 거부할 변경을 미리 잡는 것을 확인합니다.
  5. Kafka: 메시지를 보내고 변경 이벤트가 실시간으로 오는 것을 봅니다.
  6. 정합성 점검과 요청 기록을 둘러봅니다.
  7. 다 봤으면 샘플 데이터 화면에서 "정리"를 누릅니다.
이 데모 앱은 공용 개발 Atlas에 붙어 있을 수 있습니다. 샘플 데이터와 예시 입력은 console_demo_*, console_sample_*, *@demo 이름만 쓰므로 다른 데이터와 섞이지 않습니다. 직접 입력할 때도 이런 접두어를 쓰는 것을 권합니다.

Java에서 시작하기

AtlasClient atlas = AtlasClient.builder()
        .serverUrls("http://atlas:21000")
        .basicAuth("admin", "admin")
        .build();

String status = atlas.admin().status();          // "ACTIVE"
String version = atlas.admin().version().getVersion();
