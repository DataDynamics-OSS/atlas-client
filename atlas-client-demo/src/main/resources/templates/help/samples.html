무엇을 만드나요?

작은 쇼핑몰의 매출 데이터 흐름을 흉내 낸 메타데이터입니다. 라이브러리의 모든 모듈을 한 번씩 거칩니다.

1. 타입 다섯 개 (typedef 모듈의 plan/apply)

console_demo_tierENUM. 데이터 등급 BRONZE / SILVER / GOLD
console_demo_tableENTITY. DataSet을 상속한 테이블. tier, rowCount 속성 추가
console_demo_jobENTITY. Process를 상속한 작업. schedule 속성 추가
console_demo_PIICLASSIFICATION. 개인정보 표시
console_demo_qualityBUSINESS_METADATA. 품질 점수 score

2. 테이블 네 개 (core 모듈)

  • raw.orders@demo, raw.customers@demo: 원천 데이터(BRONZE)
  • mart.daily_sales@demo: 일별 매출 집계(SILVER), 품질 점수 87
  • report.sales_kpi@demo: 리포트용(GOLD), 레이블 dashboard, finance
  • raw.customers에는 PII classification을 붙입니다.

3. 작업 두 개 = 리니지 (lineage 모듈)

  • daily_sales_etl@demo: orders + customers → daily_sales
  • sales_kpi_report@demo: daily_sales → sales_kpi

버튼

  • 만들기 / 다시 만들기: 위 내용을 등록합니다. 이미 있으면 같은 것을 다시 보내므로 중복이 생기지 않고, 바꿔 놓은 값은 원래대로 돌아옵니다. 두 번째부터는 타입 plan이 모두 = unchanged로 나옵니다.
  • 정리: 샘플 엔티티를 delete → purge하고 샘플 타입 다섯 개를 지웁니다. 다른 데이터는 건드리지 않습니다.

만든 뒤에 해 볼 것

  1. 결과의 "리니지 보기"로 그래프를 봅니다.
  2. 엔티티 검색에서 classification 열을 봅니다. PII는 customers에만 붙였는데 daily_sales와 sales_kpi에도 있습니다. 리니지를 따라 전파됐기 때문입니다.
  3. daily_sales 상세 화면에서 레이블과 business metadata(score)를 바꿔 봅니다.
  4. raw.orders를 delete한 뒤 정합성 점검을 돌려 봅니다.

요청 기록으로 보는 순서

"만들기"를 누른 뒤 화면 아래 요청 표를 보면 라이브러리가 하는 일이 순서대로 보입니다.

  1. GET …/types/…: plan을 위해 현재 타입 조회
  2. POST /api/atlas/v2/types/typedefs: 없는 타입 생성
  3. POST /api/atlas/v2/entity/bulk: 테이블 네 개를 한 번에 등록
  4. POST …/businessmetadata: 품질 점수
  5. GET …/uniqueAttribute/… 여러 번: 리니지의 입력·출력 테이블이 있는지 확인
  6. POST /api/atlas/v2/entity/bulk: 작업 두 개를 한 번에 등록

Java 코드로는

manager.apply(manager.plan(
        enumType("console_demo_tier").values("BRONZE", "SILVER", "GOLD"),
        entity("console_demo_table").dataSet()
                .attribute(attr("tier", "console_demo_tier"))
                .attribute(attr("rowCount", LONG)),
        entity("console_demo_job").process().attribute(attr("schedule", STRING)),
        classification("console_demo_PII").entityTypes("console_demo_table")));

lineage.register(List.of(
        lineage.process("console_demo_job", "daily_sales_etl@demo")
                .inputs(EntityRef.of("console_demo_table", "raw.orders@demo"),
                        EntityRef.of("console_demo_table", "raw.customers@demo"))
                .outputs(EntityRef.of("console_demo_table", "mart.daily_sales@demo"))));
