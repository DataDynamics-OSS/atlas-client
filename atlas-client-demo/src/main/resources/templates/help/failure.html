빨간 상자 읽는 법

  1. 굵은 글씨: 클라이언트가 던진 예외 이름. 무엇이 문제인지 가장 먼저 알려줍니다.
  2. HTTP 상태: Atlas가 돌려준 응답 코드(있을 때)
  3. ATLAS-… 코드: Atlas의 오류 코드. 검색하면 원인을 찾기 쉽습니다.
  4. 메시지: Atlas나 클라이언트가 적은 설명

예외 종류

AtlasNotFoundException404. 없는 guid, 타입, qualifiedName
AtlasBadRequestException400. 입력 형식이 잘못됨
AtlasConflictException409. 이미 있는 것을 다시 만들려 함
AtlasUnavailableException503 등. Atlas가 시작 중이거나 대기 상태
AtlasConnectionExceptionAtlas에 연결하지 못함
IllegalArgumentExceptionAtlas에 보내기 전에 데모 앱이나 클라이언트가 입력을 거부함

모든 클라이언트 예외는 AtlasClientException을 상속하므로 Java 코드에서 한 번에 잡을 수도 있습니다.

  • 아래 요청 기록에서 실패한 요청(빨간 행)을 눌러 Atlas가 돌려준 응답 본문을 확인합니다.
  • Atlas 접속 문제라면 대시보드에서 상태를 확인합니다.
